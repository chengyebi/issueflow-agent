解锁 IssueFlow 审核台

审核任务包含 Issue 内容、Agent 判断和待执行命令。 请输入管理员 Token 后才能读取或提交审核决策。

Token 不会进入 URL，只用于同源审核 API 请求。

解锁后 Token 仅保存在当前浏览器页面会话中。 你可以随时点击“锁定审核台”立即清除。
